# خطة إصلاح توافق العميل والتاجر مع Django

هذه المرحلة مخصصة لإغلاق فروقات التكامل الظاهرة قبل بدء Storefront refactor.

النطاق:
- متجر العميل وصفحات المتاجر.
- تفاصيل الطلب وفتح المحادثة بشكل صريح.
- لوحة التاجر وملف/إعدادات المتجر وتصميم المتجر.
- إدارة أقسام المتجر والصور والبنرات.
- المحفظة، الرصيد، والسحب بعد تحرير أموال الطلب.
- الترندات والتصنيف والمنتجات المنشورة.
- توحيد عقود API المستخدمة فعليًا في العميل والتاجر.

قواعد:
1. لا تغيير لعقود API العامة إلا عند وجود خطأ مؤكد.
2. عدم حذف البيانات تشغيلًا؛ حالات الحذف/التعطيل تبقى غير مدمرة.
3. كل إصلاح واجهة يجب أن يعتمد على الاستجابة الحالية من Django.
4. لا نعتمد على بيانات ثابتة للمتاجر أو المنتجات.
5. بعد الإصلاحات يجب تشغيل TypeScript + Django checks/tests + builds.
