# تدقيق واجهات العميل والتاجر

## الإصلاحات الحالية
- تحميل المتاجر النشطة عبر جميع صفحات API بدل الاكتفاء بالصفحة الأولى.
- تحميل منتجات المتجر باستخدام مرشح `vendor` المدعوم في Django.
- عرض أقسام الواجهة المرئية حتى عندما تكون بياناتها فارغة، بدل اختفائها دون تفسير.
- ضغط صور البانرات والفئات ومنع إرسال صورة تتجاوز الحد الآمن.
- حفظ الصور الجديدة مباشرة بطلب مستقل حتى لا تتراكم بيانات Base64 في طلب حفظ واحد.
- تحويل خطأ `413 Request Entity Too Large` واستجابات HTML الخام من Nginx إلى رسالة عربية مفهومة.
- لا توجد تغييرات schema أو Migration جديدة.
