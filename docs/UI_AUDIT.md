# تدقيق واجهات العميل والتاجر

## نطاق هذه الدفعة
- إعادة تصميم مصمم واجهة المتجر بالكامل بالعربية وRTL مع معاينة حيّة وألوان جاهزة وتحكم بالأقسام.
- إعادة تصميم محرر أقسام واجهة المتجر وإضافة/حذف/ترتيب الأقسام والصور والبنرات دون تغيير عقد API.
- تحسين دليل المتاجر العامة وإظهار المتاجر النشطة عبر جميع صفحات الاستجابة، بدل الاكتفاء بالصفحة الأولى.
- إصلاح صفحة المتجر لإحضار منتجات المتجر مباشرة عبر مرشح `vendor`، مع إبقاء الأقسام المرئية ظاهرة حتى عندما تكون فارغة بدل اختفائها بصمت.
- تحسين شاشة الترندات وإزالة العبارات الإنجليزية الظاهرة للمستخدم.
- تحويل أخطاء REST/DRF الخام، بما فيها استجابة Nginx `413 Request Entity Too Large`، إلى رسائل عربية مفهومة للمستخدم.
- ضغط صور البانرات والفئات قبل الإرسال ووضع حد لحجم بيانات الصورة داخل التطبيق، مع حفظ الصورة مباشرة بعد إضافتها حتى لا تتراكم الصور المشفرة Base64 في طلب حفظ واحد.
- الحفاظ على مسارات Django الحالية وعدم ربط المستخدم مباشرة بصفحات Browsable API.

## قاعدة عامة
واجهات `/api/...` تبقى خدمات داخلية للتطبيق؛ صفحات المستخدم لا تنتقل إليها عبر روابط UI، ورسائل الأخطاء تُعرض بصياغة عربية مفهومة.

## الصور و413
العميل يمنع إرسال صورة تتجاوز الحد الآمن ويضغط الصور عند اختيارها. إضافة الصورة تحفظ القسم مباشرة عبر PATCH منفصل، لذلك لا تعتمد العملية على إعادة إرسال جميع الصور القديمة في كل عملية حفظ لاحقة. ملف Nginx الموجود في `deploy/shopik.alattab.site.nginx` يحدد `client_max_body_size`، ويجب أن تكون نسخة الخادم المستخدمة فعليًا متوافقة معه إذا كان إعداد Nginx المنشور مختلفًا عن الملف الموجود في المستودع.

## قاعدة البيانات
لا توجد تغييرات schema ولا Migration جديدة في هذه الدفعة.
