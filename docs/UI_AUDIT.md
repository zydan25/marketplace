# تدقيق واجهات العميل والتاجر

## نطاق هذه الدفعة
- إصلاح تحميل المتاجر النشطة عبر الصفحات كلها.
- إصلاح تحميل منتجات المتجر عبر مرشح `vendor`.
- إبقاء أقسام واجهة المتجر المرئية موجودة حتى عند فراغ بياناتها.
- تقليل حجم صور البانرات والفئات ومنع طلبات 413 داخل التطبيق.
- حفظ الوسائط الجديدة مباشرة بدل تجميع صور Base64 في طلب واحد.
- تحويل 413 واستجابات HTML من Nginx إلى رسائل عربية مفهومة.
- لا توجد تغييرات schema أو Migration جديدة.
