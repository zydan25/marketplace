# إعادة بناء تغييرات المنصة انطلاقًا من main

## قاعدة العمل
- المصدر الوحيد: `main` عند إنشاء فرع العمل.
- لا يتم نسخ أي ملف من `refactor/django-marketplace-foundation` إلى هذا الفرع.
- كل مرحلة تُختبر على فرع العمل، ثم تُراجع، وبعدها فقط تفتح Pull Request إلى `main`.

## المهام

### P0 — إصلاحات تمنع الاستخدام
- [ ] إصلاح فتح متجر تاجر من قائمة المتاجر وعدم ظهور 404 عندما يكون slug صالحًا.
- [ ] ضمان أن صفحة المتجر تعرض هوية المتجر + الثيم + الأقسام + المنتجات.
- [ ] فصل استعلام التصفح العام عن استعلام منتجات التاجر، حتى تظهر الترندات للمستخدمين المسجلين وغير المسجلين بنفس شروط النشر.
- [ ] توحيد محفظة التاجر مع الرصيد الفعلي واحتساب المتاح للسحب والطلبات المعلقة.

### P1 — نظام واجهة رئيسية حقيقي
- [ ] إعادة بناء عقد Storefront لتدعم Hero متعدد الشرائح.
- [ ] شريط فئات علوي قابل للتحكم.
- [ ] فئات دائرية قابلة للترتيب.
- [ ] بانرات/بطاقات ترويجية متعددة.
- [ ] تبويبات مثل: من أجلك، جديدة، تخفيضات، الأكثر مبيعًا.
- [ ] شبكات منتجات بعدد صفوف وأعمدة يحددها المدير.
- [ ] ربط شبكة المنتجات بمصدر: أحدث/الأكثر مبيعًا/التخفيضات/الترند/فئة/اختيار يدوي.
- [ ] اختيار الفئات أو المنتجات داخل كل قسم.
- [ ] توجيه كل بانر/بطاقة/زر إلى منتج أو فئة أو قسم أو رابط.
- [ ] دعم محتوى الهاتف والمحتوى العام الموجود سابقًا دون فقده.

### P1 — محرر الواجهة

- [ ] سحب/ترتيب أو على الأقل ترقيم مباشر للأقسام.
- [ ] إظهار/إخفاء.

- [ ] إدارة الصور والبنرات من نفس الشاشة.

### P1 — ثيمات التصميم
