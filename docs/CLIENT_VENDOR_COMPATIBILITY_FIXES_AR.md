# إصلاحات توافق العميل والتاجر مع Django

تم تنفيذ هذه المرحلة على branch `fix/client-vendor-compatibility-20260829`.

## الإصلاحات
- فتح تفاصيل الطلب أولًا من قائمة طلبات العميل، مع إبقاء المحادثة داخل صفحة التفاصيل.
- تصحيح رابط متجر المنتج إلى `/store/{slug}`.
- استعادة شاشة تخصيص ألوان وهوية المتجر.
- إضافة شاشة مستقلة لبيانات المتجر: الاسم والوصف والهاتف والعنوان والشعار والغلاف.
- السماح لمحرر واجهة المتجر بإضافة وحذف وترتيب الأقسام.
- دعم صور متعددة للبنرات/العروض وصور مخصصة للفئات داخل القسم.
- السماح للتاجر بالوصول إلى الأقسام المخفية لإعادة تفعيلها أو تعديلها أو حذفها.
- دعم حفظ صور الشعار والغلاف وصور أقسام المتجر من التطبيق.
- جعل شاشة الفئات في تطبيق التاجر متوافقة مع صلاحيات Django؛ الفئات الأساسية تدار مركزيًا.
- ربط إحصاءات التاجر بالمستحقات ومحفظة Django وإظهار الرصيد الفعلي والمتاح للسحب.
- إضافة دورة طلب سحب يدوية: pending → approved → paid/rejected مع خصم الصرف من المحفظة وتسجيل WalletTransaction.
- استكمال شاشة الترندات لتقرأ المنتجات ذات `is_trending` من خادم Django بدل بيانات محلية ثابتة.

## ملاحظات التحقق
- عقود `/api/auth/`, `/api/products/`, `/api/vendors/`, `/api/storefront-sections/`, `/api/orders/`, `/api/vendor-finance/` بقيت على المسارات العامة الحالية.
- حذف المنتج بقي غير مدمر؛ Django يحوله إلى غير منشور بدل حذف السجل.
- تحرير المستحقات المرتبطة بالطلب يبقى منفصلًا عن طلبات السحب اليدوية.
