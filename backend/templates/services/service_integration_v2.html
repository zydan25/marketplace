SERVICE API CONTRACT

طريقة الربط للخدمات في شبيك

العقد الجديد لا يفصل الباقة إلى Service للعرض وService للتسديد. الباقة عنصر داخل Service واحدة مدفوعة، بينما خدمات الاستعلام مستقلة وغير مالية.

← مركز الخدمات

1) اكتشاف الإعدادات

GET /api/v2/services/settings/\nGET /api/v2/services/settings/?group=yemen_mobile\nGET /api/v2/services/settings/yemen_mobile_packages/service/

الإعداد يرجع service.id وcode والاسم وعقد الخدمة. في باقات يمن موبايل سيظهر service.code = yem-offer فقط.

2) جلب كتالوج الخدمة

GET /api/v2/services/catalog/\nGET /api/v2/services/services/<service_id>/

العقد يحتوي fields وitems وplan_types. بالنسبة للباقات يتم عرض plan_types كمجموعات اختيار، ثم عرض item/plan المرتبط بها.

3) تنفيذ عملية مدفوعة

POST /api/v2/services/requests/\nAuthorization: Token <token>\nIdempotency-Key: <unique-key>\n\n{\n "service_id": 123,\n "item_type": "telecom_plans",\n "item_id": 456,\n "payload": {\n "mobile": "77xxxxxxx",\n "method": "New",\n "solfa": "N"\n }\n}

الخادم يحسب السعر من العنصر نفسه ويحجزه محاسبيًا قبل الإرسال الخارجي. لا يرسل التطبيق external_code أو offerkey يدويًا؛ النظام يشتقه من item_id.

4) متابعة العملية

GET /api/v2/services/requests/<uuid>/
queued / processing

الطلب دخل طابور التنفيذ.

pending_provider

المزود لم يحسم العملية؛ يتم إنشاء فحص حالة عندما يكون مسار الحالة متاحًا.

success / refunded / manual_review

لا يقرر التطبيق النجاح من HTTP 200 فقط؛ يعتمد على حالة المعاملة النهائية.

5) الخدمات التي لا تظهر ضمن العمليات المالية

كل Service من النوع query مثل استعلام الرصيد واستعلام الباقات والاستعلامات العامة تبقى متاحة في الكتالوج، لكنها لا تظهر في شاشة العمليات المالية الجديدة.

6) الألعاب والبطاقات

كل لعبة/بطاقة لها Service ثابت باسمها لأن عقد المزود يستخدم type = service.code. العناصر والفئات التابعة لها تظهر داخل خدمة اللعبة ولا يتم خلطها مع خدمات الاتصالات.

7) ملاحظات التشغيل

الاعتمادات الخاصة بالمزود تبقى على الخادم فقط. لا يضع التطبيق userid أو password أو token. في Yemen Mobile تستخدم خدمة الباقات نفسها New / Renew / Remove، ويُرسل مزود صنعاء كاش عبر عقد offeryem مع offerkey/method/solfa.
